# 重要事項説明書 クロスチェック（統合済み）

このリポジトリの機能は **`jyusetsu-app`（重説システム）へ統合済み**です。

- 統合先: https://github.com/kyouei-higuma/jyusetsu-app  
- 社内サーバーで `jyusetsu-app` を起動すると、サイドバーから「📄 クロスチェック」ページを利用できます。

今後の開発・運用・改善要望への対応は **jyusetsu-app 側のみ**で行います。  
Streamlit Cloud 上の本アプリは、社内サーバー移行完了後に停止してください。

（履歴としてコードは残していますが、新規機能追加は行いません。）
